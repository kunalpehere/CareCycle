# CareCycle

CareCycle is a medical-equipment donation platform that connects donors with verified NGOs. Donors list equipment, NGOs request the quantities they need, and donors review requests and coordinate the donation.

## What users can do

### Donors

- Create equipment listings with condition, quantity, location and optional images.
- Edit or withdraw available listings.
- Review NGO requests and accept or reject them.
- Track allocated equipment and donation history.
- Exchange contact information after accepting a request.

### NGO members

- Submit an organization profile for verification.
- Browse and filter available equipment after approval.
- Request equipment and track request progress.
- Cancel pending requests.
- Coordinate collection with donors after acceptance.

### Administration

- Review organization verification evidence.
- Approve or reject NGO applications.
- Review activity and moderate participant accounts.

Organization verification does not certify equipment condition or medical suitability.

## Technology

- Node.js and Express
- MongoDB and Mongoose
- EJS, HTML and CSS

## Live demo

[Try the live CareCycle demo](https://carecycle-demo.onrender.com/demo)

The demo uses clearly labelled fictional accounts and equipment. Visitors can try donor and NGO roles. Real donations, personal registration, uploads and administrative access are unavailable in the public demo.
