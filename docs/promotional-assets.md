## Stylesheet retirement

All template stylesheet/script references were inspected. `public/style.css`, `public/contact.css`, and `public/donate.css` had no current template references. Their legacy decorative styles were retired, including unused purple contact styles. Active forms use `donor.css` or `content-pages.css` with `app.css`. The shared animation-only `transitions.js` and its template references were removed; navigation uses browser behavior immediately. `accessibility.js` and `app-nav.js` remain loaded.

## Evidence required before reintroducing an asset

Record the original source URL or owner, licence/permission text and date, permitted uses, required credit, and the intended location in the interface. For participant media, obtain appropriate permission for any promotional reuse separately from listing display. An illustrative photograph must be labelled as illustrative and must not imply available stock or inspected condition.

Existing `docs/screenshots` and the README showcase depict the earlier interface. They are historical previews, not permission evidence or proof of the cleaned interface. Day 28 requires refreshed showcase media; the README identifies this limitation meanwhile.
